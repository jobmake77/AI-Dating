# 普通用户测试用例矩阵（功能点 → 正常 / 越权 / 边界）

> 说明：本矩阵以普通用户视角进行功能验证与权限边界检查。适用于本地或测试环境。

## 1) 账号与登录
**功能点**：邮箱登录/注册、GitHub OAuth
- 正常：
  - 使用合法邮箱+密码登录成功
  - 注册新邮箱成功（如需验证邮箱则提示正确）
  - OAuth 登录成功并回跳首页
- 越权：
  - 使用普通用户尝试访问 /admin/* 页面应被拒绝
  - 普通用户不能通过登录接口获取管理员数据
- 边界：
  - 错误密码、空字段、极长邮箱
  - OAuth 回调缺少 code / code 过期

## 2) 个人资料
**功能点**：更新资料、查看用户主页
- 正常：
  - 更新昵称、头像链接成功
  - 访问 /u/[username] 正常展示
- 越权：
  - 普通用户不能修改他人资料
- 边界：
  - 超长用户名、非法字符
  - 头像 URL 非法/空

## 3) 内容发布与管理
**功能点**：创建/编辑/删除内容
- 正常：
  - 创建内容成功，跳转到详情页
  - 编辑内容成功
  - 删除内容成功
- 越权：
  - 普通用户不能编辑/删除他人内容
- 边界：
  - 内容为空/超长/包含 HTML
  - 重复提交

## 4) 评论
**功能点**：发表评论、删除评论
- 正常：
  - 创建评论成功
  - 删除自己评论成功
- 越权：
  - 不能删除他人评论
- 边界：
  - 评论为空/超长/包含脚本

## 5) 点赞与转发
**功能点**：点赞/取消、转发/取消
- 正常：
  - 点赞成功，再次点击取消
  - 转发成功，再次点击取消
- 越权：
  - 非登录状态禁止操作
- 边界：
  - 重复请求多次切换

## 6) 关注
**功能点**：关注/取消关注
- 正常：
  - 关注成功，再次点击取消
- 越权：
  - 非登录状态禁止操作
- 边界：
  - 关注自己（应拒绝或忽略）

## 7) 社区（Communities）
**功能点**：创建/加入/退出/管理社区
- 正常：
  - 创建社区成功
  - 加入/退出社区成功
- 越权：
  - 普通用户不能修改/删除他人社区
  - 普通用户不能调整成员角色
- 边界：
  - 社区名称过长/重复
  - slug 非法

## 8) 社区帖子
**功能点**：创建/编辑/删除/点赞/置顶/锁定
- 正常：
  - 创建帖子成功

- 越权：
  - 普通用户不能删除他人帖子

- 边界：

## 9) 私信/聊天

## 10) 通知
**功能点**：读取/标记/删除通知
- 正常：

## 11) 搜索与推荐
**功能点**：搜索内容/用户、推荐/趋势
- 正常：

- 边界：

**功能点**：标签搜索/绑定/解绑
