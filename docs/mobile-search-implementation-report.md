## 用户体验流程

### 搜索流程
1. 用户点击右上角搜索图标
2. 打开全屏搜索模态框
3. 显示搜索历史和热门标签
4. 用户输入搜索关键词
5. 实时显示搜索结果（防抖 500ms）
6. 点击结果跳转到对应页面
7. 搜索记录自动保存到历史

### 搜索历史
- 自动保存最近 10 次搜索
- 点击历史项快速搜索
- 一键清除所有历史
- 数据存储在 localStorage

### 热门标签
- 显示前 10 个热门标签
- 显示标签使用次数
- 点击标签快速搜索

## 技术细节

### 性能优化
1. **防抖搜索**: 500ms 延迟，减少不必要的 API 请求
2. **懒加载**: 仅在模态框打开时加载热门标签
3. **本地存储**: 搜索历史存储在客户端，无需服务器请求

### 开发者使用
```tsx
// 在任何组件中使用移动搜索模态框
import { MobileSearchModal } from '@/components/search/mobile-search-modal'

function MyComponent() {
  const [open, setOpen] = useState(false)

  return (
    <>
      <button onClick={() => setOpen(true)}>打开搜索</button>
      <MobileSearchModal open={open} onOpenChange={setOpen} />
    </>
  )
}
```
