## 交互流程

### 流程 1: 使用搜索历史
```
1. 点击搜索图标 🔍
   ↓
2. 打开搜索模态框
   ↓
3. 看到搜索历史
   ↓
4. 点击历史项（如"React"）
   ↓
5. 自动搜索并显示结果
   ↓
6. 点击结果查看详情
```

### 流程 2: 使用热门标签
```
1. 点击搜索图标 🔍
   ↓
2. 打开搜索模态框
   ↓
3. 看到热门标签
   ↓
4. 点击标签（如"#技术"）
   ↓
5. 自动搜索并显示结果
   ↓
6. 点击结果查看详情
```

### 流程 3: 手动输入搜索
```
1. 点击搜索图标 🔍
   ↓
2. 打开搜索模态框
   ↓
3. 在搜索框输入关键词
   ↓
4. 等待 500ms（防抖）
   ↓
5. 自动显示搜索结果
   ↓
6. 点击结果查看详情
   ↓
7. 搜索自动保存到历史
```

### 流程 4: 清除搜索历史
```
1. 点击搜索图标 🔍
   ↓
2. 打开搜索模态框
   ↓
3. 看到搜索历史
   ↓
4. 点击"清除"按钮
   ↓
5. 搜索历史被清空
```

## 响应式设计

### 移动端（< 768px）
- 显示搜索图标按钮
- 点击打开全屏搜索模态框
- 触摸友好的大按钮

### 桌面端（≥ 768px）
- 隐藏搜索图标按钮
- 保持原有搜索框功能
- 不显示移动搜索模态框

## 性能特性

### 防抖搜索
```
用户输入: R → e → a → c → t
         ↓   ↓   ↓   ↓   ↓
等待时间: 500ms 后才发起请求
         ↓
API 请求: 仅发起 1 次请求（搜索"React"）
```

**优势**:
- 减少不必要的 API 请求
- 提升用户体验
- 降低服务器负载

### 本地存储
```
搜索历史存储位置: localStorage
键名: 'ai-dating-search-history'
格式: ["React", "Next.js", "AI", ...]
最大数量: 10 条
```

**优势**:
- 无需服务器请求
- 即时加载
- 隐私保护（仅本地存储）

## 可访问性

### 键盘导航
- Tab: 在元素间切换
- Enter: 执行搜索
- Esc: 关闭模态框

### 屏幕阅读器
- 搜索框有 aria-label
- 按钮有语义化标签
- 结果有清晰的结构
