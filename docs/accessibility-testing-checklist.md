## 1. 键盘导航测试

### 基本导航
- [ ] 按 Tab 键可以在所有交互元素之间导航
- [ ] 焦点顺序符合逻辑（从上到下，从左到右）
- [ ] 按 Shift+Tab 可以反向导航
- [ ] 焦点指示器清晰可见（2px 轮廓）

### 跳转链接
- [ ] 页面加载后按 Tab 键，第一个焦点是"跳到主内容"链接
- [ ] "跳到主内容"链接在获得焦点时可见
- [ ] 按 Enter 键可以跳转到主内容区域

### 导航菜单
- [ ] 可以使用 Tab 键访问所有导航链接
- [ ] 按 Enter 键可以激活链接
- [ ] "我的社区"折叠按钮可以用 Space 或 Enter 键展开/收起

### 编辑器
- [ ] 可以使用 Tab 键进入编辑器
- [ ] 可以使用 Tab 键访问所有工具栏按钮
- [ ] Ctrl+B 可以切换加粗
- [ ] Ctrl+I 可以切换斜体
- [ ] 工具栏按钮可以用 Space 或 Enter 键激活

### 表单
- [ ] 可以使用 Tab 键在表单字段之间导航
- [ ] 可以使用 Space 键选中复选框
- [ ] 可以使用方向键在单选按钮之间导航

## 3. 屏幕阅读器测试

### 推荐工具
- Windows: NVDA (免费) 或 JAWS
- macOS: VoiceOver (内置)
- iOS: VoiceOver (内置)
- Android: TalkBack (内置)

### 基本测试
- [ ] 屏幕阅读器可以读取页面标题
- [ ] 屏幕阅读器可以读取所有导航链接
- [ ] 屏幕阅读器可以读取按钮的标签
- [ ] 屏幕阅读器可以读取表单字段的标签
- [ ] 屏幕阅读器可以识别当前页面（aria-current）

### Landmarks
- [ ] 屏幕阅读器可以识别主内容区域（main）
- [ ] 屏幕阅读器可以识别导航区域（nav）
- [ ] 屏幕阅读器可以识别侧边栏（aside）
- [ ] 可以使用 landmarks 快速导航

### ARIA 属性
- [ ] 折叠按钮的展开/收起状态被正确读取（aria-expanded）
- [ ] 切换按钮的按下状态被正确读取（aria-pressed）
- [ ] 错误的输入框被标记为无效（aria-invalid）
- [ ] 上传进度被实时读取（aria-live）

### 图标和图片
- [ ] 装饰性图标不被读取（aria-hidden="true"）
- [ ] 有意义的图标有替代文本
- [ ] 用户头像有适当的 alt 文本或 aria-label

## 5. 颜色对比度测试

### 工具
- Chrome DevTools (检查元素 > Accessibility 面板)
- [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/)

### 检查项目
- [ ] 正文文本与背景的对比度 ≥ 4.5:1
- [ ] 大文本（18pt+）与背景的对比度 ≥ 3:1
- [ ] 按钮文本与背景的对比度 ≥ 4.5:1
- [ ] 链接文本与背景的对比度 ≥ 4.5:1
- [ ] 焦点指示器与背景的对比度 ≥ 3:1
- [ ] 错误消息文本与背景的对比度 ≥ 4.5:1

## 附录：常用键盘快捷键

### 浏览器导航
- Tab: 前进到下一个可聚焦元素
- Shift+Tab: 后退到上一个可聚焦元素
- Enter: 激活链接或按钮
- Space: 激活按钮或复选框
- Esc: 关闭对话框或菜单
- 方向键: 在单选按钮或选项卡之间导航

### 屏幕阅读器快捷键 (NVDA)
- Insert+Down: 开始阅读
- H: 跳转到下一个标题
- D: 跳转到下一个 landmark
- B: 跳转到下一个按钮
- F: 跳转到下一个表单字段
- K: 跳转到下一个链接

### 屏幕阅读器快捷键 (VoiceOver)
- Control+Option+A: 开始阅读
- Control+Option+Command+H: 跳转到下一个标题
- Control+Option+Command+L: 跳转到下一个链接
- Control+Option+Command+J: 跳转到下一个表单控件
