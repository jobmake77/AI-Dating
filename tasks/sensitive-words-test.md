# 敏感词检测系统测试

## 测试日期：2026-02-16

## 功能说明

内容发布时自动检测敏感词：
- ✅ 有敏感词 → 拒绝发布，显示错误提示
- ✅ 无敏感词 → 直接发布（approved 状态）

## 测试用例

### 1. 正常内容发布

**测试步骤：**
1. 访问 `/create`
2. 输入正常内容："如何使用 React Hooks 优化性能"
3. 点击"发布"

**预期结果：**
- ✅ 发布成功
- ✅ 重定向到内容详情页
- ✅ 内容状态为 `approved`
- ✅ 内容在首页显示

### 2. 包含敏感词的内容

**测试步骤：**
1. 访问 `/create`
2. 输入包含敏感词的内容（例如包含"赌博"、"色情"等词）
3. 点击"发布"

**预期结果：**
- ✅ 发布失败
- ✅ 显示错误提示："内容包含敏感词：xxx。请修改后重新发布。"
- ✅ 内容未创建
- ✅ 用户停留在发布页面
- ✅ 已输入的内容不丢失

### 3. HTML 标签中的敏感词

**测试步骤：**
1. 访问 `/create`
2. 输入包含 HTML 标签的内容，标签内有敏感词
3. 点击"发布"

**预期结果：**
- ✅ 正确检测到敏感词（去除 HTML 标签后检测）
- ✅ 发布失败并提示

### 4. 大小写混合的敏感词

**测试步骤：**
1. 访问 `/create`

3. 点击"发布"

**预期结果：**
- ✅ 正确检测到敏感词（不区分大小写）
- ✅ 发布失败并提示

## 敏感词列表

当前系统包含以下类别的敏感词：

### 政治敏感词
- 习近平、胡锦涛、江泽民、毛泽东、邓小平
- 共产党、中共、政府、党中央

### 暴力相关
- 杀人、自杀、爆炸、恐怖、暴力

### 色情相关
- 色情、黄色、裸体、性交、porn

### 赌博相关
- 赌博、博彩、六合彩、赌场

### 违法相关
- 毒品、贩毒、走私、洗钱、诈骗

### 其他
- 法轮功、邪教

## 扩展敏感词列表

如需添加更多敏感词，编辑文件：
`/lib/utils/sensitive-words.ts`

在 `SENSITIVE_WORDS` 数组中添加新词即可。

## 管理员审核界面（备用）

虽然现在是自动审核，但保留了管理员审核界面作为备用：
- 访问 `/admin/moderation` 查看所有内容
- 可以手动批准或拒绝内容
- 适用于特殊情况的人工干预

## 注意事项

1. **敏感词列表需要定期更新**
   - 根据实际情况添加新的敏感词
   - 删除误判的词

2. **误判处理**
   - 如果正常词被误判，从列表中移除
   - 考虑使用更精确的匹配规则

3. **性能考虑**
   - 当前使用简单的字符串匹配
   - 敏感词列表不宜过长（建议 < 1000 个）
   - 如需更复杂的检测，考虑集成第三方 API

4. **未来优化方向**
   - 集成阿里云内容安全 API
   - 使用正则表达式匹配
   - 添加白名单机制
   - 上下文分析（避免误判）
