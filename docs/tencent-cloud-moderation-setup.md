# 腾讯云天御内容安全配置指南

## 为什么选择腾讯云天御？

- ✅ **语义分析**：不是简单的关键词匹配，能理解上下文
- ✅ **免费额度**：每月 10000 条免费（足够 MVP 使用）
- ✅ **准确率高**：误判率低，不会错杀正常内容
- ✅ **多维度检测**：色情、政治、违法、广告、谩骂、暴恐等

## 配置步骤

### 1. 注册腾讯云账号

访问：https://cloud.tencent.com/

### 2. 开通天御内容安全服务

1. 访问：https://console.cloud.tencent.com/cms/text/overview
2. 点击"立即开通"
3. 选择"按量计费"（每月前 10000 条免费）

### 3. 获取 API 密钥

1. 访问：https://console.cloud.tencent.com/cam/capi
2. 点击"新建密钥"
3. 复制 `SecretId` 和 `SecretKey`

### 4. 配置环境变量

编辑 `.env.local` 文件，添加：

```env
# 腾讯云天御内容安全
TENCENT_SECRET_ID=your_secret_id_here
TENCENT_SECRET_KEY=your_secret_key_here
```

**重要提示：**
- ⚠️ 不要将密钥提交到 Git
- ⚠️ `.env.local` 已在 `.gitignore` 中

### 5. 重启开发服务器

```bash
npm run dev
```

## 工作原理

### 发布内容时：

1. 用户填写内容并点击"发布"
2. 系统调用腾讯云 API 检测内容
3. **检测结果：**
   - `Pass`（通过）→ 直接发布
   - `Review`（建议人工审核）→ 拒绝发布，提示修改
   - `Block`（拒绝）→ 拒绝发布，提示违规类型

### 检测类型：

| 类型 | 说明 | 示例 |
|------|------|------|
| Porn | 色情内容 | 色情图片、文字描述 |
| Sexy | 性感内容 | 低俗、性暗示 |
| Polity | 政治敏感 | 政治人物、敏感事件 |
| Illegal | 违法违规 | 毒品、赌博、诈骗 |
| Abuse | 谩骂内容 | 侮辱、人身攻击 |
| Terror | 暴恐内容 | 暴力、恐怖主义 |
| Ad | 广告内容 | 垃圾广告、营销 |

## 费用说明

### 免费额度：

- 每月前 **10000 条**免费
- 对于 MVP 阶段完全够用

### 超出免费额度后：

- 文本检测：约 ¥0.0025/条
- 例如：每月 20000 条 = 10000 条免费 + 10000 条付费 = ¥25

### 成本优化建议：

1. **本地预检**：先用简单规则过滤明显违规内容
2. **缓存结果**：相同内容不重复检测
3. **批量检测**：多条内容合并检测

## 故障处理

### 如果 API 调用失败：

系统会自动降级：
- 记录错误日志
- 为了安全，拒绝发布
- 提示用户稍后重试

### 如果未配置密钥：

系统会跳过审核：
- 打印警告日志
- 直接发布内容（开发环境）

## 常见问题

### Q: 会不会误判正常内容？

A: 腾讯云使用语义分析，误判率很低。如果遇到误判，可以：
1. 联系腾讯云客服反馈
2. 在管理后台手动批准

### Q: 检测速度如何？

A: 通常在 100-300ms 内返回结果，用户感知不明显。

### Q: 可以自定义敏感词吗？

A: 可以，在腾讯云控制台配置自定义词库。

### Q: 支持哪些语言？

A: 支持中文、英文等多种语言。
