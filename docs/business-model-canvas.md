## 十二、单位经济模型 (Unit Economics)

### 关键指标计算

**CAC (获客成本)**
```
首月获客: 100人
推广投入: ¥0（纯organic）
时间成本: 100小时 × ¥50/小时 = ¥5,000
有效CAC: ¥5,000 ÷ 100 = ¥50/人

目标: CAC < 3个月收入 = ¥19.9 × 3 = ¥59.7
结果: ✅ ¥50 < ¥59.7，达标
```

**LTV (用户终身价值)**
```
月均收入: ¥19.9
平均留存: 6个月（保守估计）
LTV: ¥19.9 × 6 = ¥119.4

目标: LTV > 3× CAC = ¥150
结果: ⚠️ ¥119.4 略低于 ¥150，需优化留存
```

**回本周期**
```
回本周期: CAC ÷ 月ARPU = ¥50 ÷ ¥19.9 = 2.5个月
目标: < 12个月
结果: ✅ 远低于目标
```

**关键改进点**: 提升留存至8个月，LTV可达¥159.2，即可达标
