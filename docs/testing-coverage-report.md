## 运行测试

```bash
# 运行所有单元测试
npm run test

# 运行单元测试（单次）
npm run test:run

# 运行测试并生成覆盖率报告
npm run test:coverage

# 运行 E2E 测试
npm run test:e2e

# 运行 E2E 测试（UI 模式）
npm run test:e2e:ui

# 运行 E2E 测试（调试模式）
npm run test:e2e:debug
```
