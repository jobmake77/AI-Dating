# AI-Dating 5天极简上线计划

**约束条件**：
- 0预算（只用免费资源）
- 单人全职
- 无支付渠道（MVP阶段手动处理）
- 5天上线

---

## Day 1: 技术选型与基础搭建

### 上午（4小时）
**选择技术栈**（免费+快速）：
- 前端：Next.js + Vercel（免费托管）
- 后端：Next.js API Routes + PostgreSQL（Supabase免费版）
- 认证：NextAuth.js（GitHub/Google登录，免费）
- 存储：Vercel Blob / Supabase Storage（免费额度）
- 富文本：MDX或Markdown编辑器

### 下午（4小时）
- 初始化项目
- 配置数据库Schema（最简化版本）
- 搭建认证系统（GitHub登录）

**最小数据库表**：
```sql
-- users: 用户表
-- contents: 内容表
-- subscriptions: 订阅表（手动标记）
```

---

## Day 2: 核心功能开发

### 上午（4小时）
- 内容发布功能（Markdown编辑器）
- 内容列表页
- 内容详情页

### 下午（4小时）
- 内容审核标记（简单字段：pending/approved/rejected）
- 敏感词检测（阿里云API免费额度或先不做）
- 用户个人主页

---

## Day 3: 订阅功能+AI助手

### 上午（4小时）
**订阅功能（简化版）**：
- 由于无支付渠道，采用"手动开通会员"
- 用户在页面上点击"订阅"→弹出提示"联系客服开通"
- 你手动在数据库标记为会员
- 或者：先不做支付，所有人免费，收集反馈

### 下午（4小时）
- 接入AI助手（LangChain + OpenAI API或国产大模型）
- 简单RAG：让AI能读取社区内容回答

---

## Day 4: 内容填充+UI优化

### 上午（4小时）
- 联系种子创作者，收集首批内容
- 自己写3-5篇内容作为示例
- 确保不同类型的技术内容都有覆盖

### 下午（4小时）
- UI美化（Tailwind CSS快速搭建）
- 响应式适配（移动端必须能用）
- SEO优化（标题、描述）

---

## Day 5: 上线+推广

### 上午（4小时）
- 部署到Vercel（一键部署）
- 配置域名（用Vercel自带免费域名或你已有域名）
- 简单测试（注册、发布、浏览）

### 下午（4小时）
**冷启动推广**：
1. 发朋友圈/技术群："新做的AI开发者社区，邀请码XXX"
2. 私聊种子创作者，请他们发布内容
3. 在技术论坛（V2EX、掘金、知乎）发软广
4. 直播首播（ yourself 技术分享）
