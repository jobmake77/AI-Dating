## 使用指南

### 开发者如何使用

#### 1. 查看文档
```bash
# 从 API 概览开始
open docs/api/README.md

# 学习认证
open docs/api/authentication.md

# 查看端点详情
open docs/api/endpoints.md
```

#### 2. 运行示例

**Python**:
```bash
cd examples/python
cp .env.example .env
# 编辑 .env 文件
pip install -r requirements.txt
python get_posts.py
python create_post.py
```

**Node.js**:
```bash
cd examples/nodejs
cp .env.example .env
# 编辑 .env 文件
npm install
node get-posts.js
node create-post.js
```

**cURL**:
```bash
cd examples/curl
# 编辑 examples.sh，设置 API_KEY
chmod +x examples.sh
./examples.sh
```

#### 3. 集成到项目

根据示例代码，将 API 调用集成到自己的项目中。
