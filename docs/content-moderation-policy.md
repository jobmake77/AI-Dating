# AI-Dating 开发者社区 - 内容审核规则

**版本**: v1.0  
**生效日期**: 待确定  
**适用范围**: 所有注册用户发布的内容（文章、评论、直播、私信）

## 一、审核原则

### 1.1 总体方针
- **前期宽松，后期严格**：冷启动阶段（前1000用户）以引导教育为主，成熟期严格执行
- **算法+人工**：机器初审 + 人工复审 + 用户举报
- **透明可申诉**：所有处罚都有明确依据，支持申诉

### 1.2 内容定位
本社区为**AI开发者技术社区**，内容应围绕：
- 编程技术、开源项目
- AI/机器学习应用
- 开发者工具与经验
- 职业发展、技术面试

## 二、违规内容分级

### 🔴 一级违规（严重违规）
**处理**：永久封号，内容删除，保留追究法律责任权利

| 类别 | 具体描述 | 示例 |
|------|----------|------|
| **政治敏感** | 涉及国家法律法规禁止的内容 | *具体标准不公开，依据法规及监管要求判定* |
| **色情低俗** | 性暗示、色情内容、低俗图片/视频 | 露骨描述、色情代码仓库推广 |
| **暴力恐怖** | 暴力、恐怖主义、极端主义内容 | 暴力手段教学、恐怖组织宣传 |
| **违法犯罪** | 毒品、赌博、诈骗、黑客攻击教程 | 爬虫绕过登录、破解软件分享 |
| **侵犯隐私** | 泄露他人隐私信息 | 手机号、身份证、住址曝光 |
| **恶意软件** | 传播病毒、木马、挖矿程序 | 伪装开源项目的恶意代码 |

### 🟠 二级违规（一般违规）
**处理**：删帖 + 警告，累计3次禁言7天，累计5次封号

| 类别 | 具体描述 | 示例 |
|------|----------|------|
| **人身攻击** | 辱骂、歧视、 harassment | 傻逼、废物、地域歧视 |
| **引战吵架** | 煽动对立、无意义争论 | 需结合语境和语义判断（见下文详细标准）|
| **广告软文** | 未经平台许可的商业推广 | 冷启动期暂不严格限制（见6.3节）|
| **抄袭洗稿** | 搬运他人内容不注明出处 | 复制GitHub README不标注来源 |
| **标题党** | 严重误导性标题 | "震惊！某大厂程序员竟然..." |
| **无关内容** | 与开发者社区无关的内容 | 美食、旅游、明星八卦 |

### 2.2.5 引战判定标准（语境+语义）

**核心原则**：结合上下文语境和表达语义综合判断，非单一关键词判定

| 场景 | 示例 | 判定 |
|------|------|------|
| 技术对比讨论 | "Go的并发模型比Python更适合高并发场景" | ✅ 允许 |
| 带嘲讽的攻击 | "用Python的都是菜鸟，Go才是工程师的选择" | ❌ 违规 |
| 幽默自嘲 | "PHP是世界上最好的语言（狗头）" | ✅ 允许 |
| 恶意挑事 | "Vue和React用户吵一架，看看谁更蠢" | ❌ 违规 |

**判断维度**：
- 是否有技术事实依据 → 允许
- 是否针对人群人身攻击 → 违规
- 语气是否友善、建设性 → 允许
- 是否故意挑起无意义争吵 → 违规

---
**处理**：限流、降权、提示优化，不处罚账号

| 类别 | 具体描述 | 示例 |
|------|----------|------|
| **水帖** | 无实质内容 | "沙发"、"占楼"、纯表情 |
| **格式混乱** | 代码无高亮、排版混乱 | 大段代码不格式化、无段落 |
| **重复发布** | 同一内容多次发布 | 刷屏、重复提问 |
| **提问不规范** | 不描述问题、不贴代码 | "有人吗？"、"这个怎么报错？"（无详情）|
| **错版块** | 内容发布在错误板块 | 求职信息发到技术讨论区 |

## 三、特殊内容规范

### 3.1 代码分享
✅ **允许**：
- 开源项目推荐（附GitHub链接）
- 原创代码分享
- 学习笔记、踩坑记录

❌ **禁止**：
- 商业软件破解代码
- 侵犯版权的完整项目代码
- 包含密钥、密码的代码片段

### 3.2 AI相关内容
✅ **允许**：
- AI模型部署教程
- 开源模型使用经验
- AI工具推荐与评测

❌ **禁止**：
- 深度伪造（Deepfake）教程
- 用于欺诈的AI生成内容
- 绕过AI安全机制的方法

### 3.3 直播内容
✅ **允许**：
- 编程实战直播
- 代码Review
- 技术分享

❌ **禁止**：
- 直播中出现违规内容（同上文分级）
- 长时间无技术内容的闲聊
- 诱导打赏、私下交易

### 3.4 创作者推广
✅ **允许**（认证创作者）：
- 个人技术博客/公众号引流（文末附链接）
- 付费课程推广（需标注"推广"）
- 开源项目求Star

❌ **禁止**：
- 未认证用户发布推广内容
- 过度推广（单篇内容推广占比超50%）
- 虚假宣传、夸大效果

## 四、审核流程

### 4.1 发布前审核（机器审核）
```
用户发布 → 阿里云内容安全API检测 → 
├─ 通过 → 发布上线
├─ 疑似违规 → 进入人工审核队列（延迟显示）
└─ 确认违规 → 拦截发布，提示修改
```

**检测维度**：
- 文本：敏感词、政治、色情、广告
- 图片：OCR识别文字、违规图像识别
- 链接：黑名单域名检测

### 4.2 发布后审核
- **随机抽查**：已发布内容5%进入复审
- **用户举报**：收到举报后24小时内处理
- **算法复核**：高流量内容自动触发复核

### 4.3 人工审核标准
| 场景 | 处理方式 |
|------|----------|
| 机器误判 | 放行，标记为误报优化模型 |
| 边界内容 | 根据上下文判断，倾向宽松 |
| 恶意举报 | 驳回举报，警告举报人 |
| 无法确定 | 先隐藏，联系作者补充说明 |

## 五、处罚与申诉

### 5.1 处罚措施

| 违规次数 | 处罚措施 |
|----------|----------|
| 首次一级违规 | 永久封号 |
| 首次二级违规 | 删帖 + 警告 |
| 累计3次二级违规 | 禁言7天 |
| 累计5次二级违规 | 永久封号 |
| 三级违规 | 不限流，仅提示优化 |

### 5.2 申诉流程
```
用户收到处罚通知 → 7天内提交申诉 → 
├─ 申诉成立 → 撤销处罚，恢复内容
└─ 申诉驳回 → 维持处罚，说明理由
```

**申诉渠道**：
- 站内申诉表单
- 邮件：appeal@ai-dating.dev（示例）
- 处理时效：3个工作日内

## 六、冷启动期特殊规则

**适用期间**：上线至第1000个注册用户

### 6.1 宽松政策
- 三级违规不处理，仅提示优化建议
- 二级违规首次不处罚，发送教育消息
- 人工审核优先教育引导，而非直接处罚

### 6.3 广告政策（冷启动期暂行）
**前1000用户阶段暂不严格限制广告**，要求：
- 内容与开发者技术相关
- 不过度刷屏（同一账号每日推广内容≤2篇）
- 不虚假宣传、不欺诈

**成熟期后**：仅认证创作者可发布推广内容

---
- 一级违规仍严格处理（封号）
- 重点观察是否有恶意刷量、薅羊毛行为
