         │

## 关键决策点

```
┌──────────────────────────────────────────────────────────┐
│  决策点 1: 是否创建备份?                                 │
│  ├─ 是 → 继续 (推荐)                                     │
│  └─ 否 → 风险自负                                        │

┌──────────────────────────────────────────────────────────┐
│  决策点 2: 推送迁移确认                                  │

└──────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────┐
│  决策点 3: 迁移失败处理                                  │
│  ├─ 查看错误 → 修复 → 重试                              │
│  ├─ 跳过该迁移 → 继续                                    │
│  └─ 回滚到备份 → 重新规划                               │
└──────────────────────────────────────────────────────────┘
```

## 错误处理流程

```
迁移执行中...
    │
    ├─ 成功 ✓
    │   └─ 继续下一个迁移
    │
    └─ 失败 ✗
        │
        ├─ 表已存在
        │   └─ 跳过或删除后重试
        │
        ├─ 外键约束失败
        │   └─ 检查数据完整性
        │
        ├─ RLS 策略冲突
        │   └─ 删除旧策略
        │
        └─ 其他错误
            └─ 查看详细日志
                │
                ├─ 可修复 → 修复后重试
                └─ 不可修复 → 回滚到备份
```

## 快速命令参考卡

```bash
# 一键完成所有步骤 (假设已登录)
supabase link --project-ref elufwtaomearxmbsshad && \
supabase db push && \
supabase gen types typescript --linked > types/database.types.ts && \
echo "✅ 迁移完成!"

# 查看状态
supabase status

# 查看迁移列表
supabase migration list

# 查看数据库 URL
supabase db url --linked

# 验证迁移
psql "$(supabase db url --linked)" -f verify-migration.sql

# 重新生成类型
supabase gen types typescript --linked > types/database.types.ts
```

## 故障排除快速索引

| 问题 | 命令 | 说明 |
|------|------|------|
| 登录失败 | `rm -rf ~/.supabase && supabase login` | 清除缓存重新登录 |
| 链接失败 | `supabase link --project-ref ... --password ...` | 使用密码参数 |
| 查看详细错误 | `supabase db push --debug` | 启用调试模式 |
| 检查迁移状态 | `supabase migration list` | 查看已应用迁移 |
| 查看数据库差异 | `supabase db diff --linked` | 对比本地和远程 |
