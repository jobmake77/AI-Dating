# 页面数据审计

日期：2026-03-13

## 审计范围

本次检查覆盖了生产环境面向用户的主要页面与对应组件，重点排查：

- 直接硬编码的列表、统计数字、热门项
- 页面展示字段与数据库表字段是否一致
- 可以接真实数据库但仍使用本地占位的区域

排除范围：

- `__tests__`
- `e2e`
- `docs`
- `examples`
- `impeccable`
- `tasks`
- `research`
- `test-ui`、`test-auth` 这类测试页面

## 本次已修复

### 1. 首页

已移除或替换以下硬编码数据：

- 欢迎区统计：改为真实聚合
  - `users` 总量
  - `contents` 已发布总量
  - `communities` 公开社区总量
- 左侧“我的社区 / 推荐社区”：改为真实社区数据
  - 登录用户优先读取 `community_members -> communities`
  - 无登录或无已加入社区时，回退为真实热门社区
- 左侧“热门社区”：改为真实 `communities.members_count / posts_count`
- 右侧“社区简报”：改为真实聚合统计
- 右侧“活跃社区”：改为真实 `communities`
- 右侧“热门标签”：改为真实 `tags.usage_count`

### 2. 搜索页

已移除硬编码的：

- 热门搜索词
- 热门标签示例数据
- “标签搜索开发中”假占位

已改为真实数据：

- 无搜索词时读取 `tags.usage_count` 作为热门标签
- 搜索时同时检索：
  - `contents`
  - `users`
  - `tags`

### 3. 管理后台首页

已移除伪造统计：

- `活跃用户 = 总用户 * 0.15`
- `+8%` 这种固定增长文案

已改为真实统计：

- `活跃作者` = 最近 30 天有发帖的去重作者数
- `已发布内容` = `contents.status = approved` 的真实数量

## 当前页面与数据库一致的区域

### 首页内容流

- 查询：`contents` + `reposts` + `users` + `follows`
- 页面 tab：
  - 热门
  - 最新
  - 关注

### 用户引导进度

- 查询：`user_onboarding`

### 搜索页

- 内容搜索：`contents`
- 用户搜索：`users`
- 标签搜索：`tags`

### 社区侧栏

- 社区列表：`communities`
- 用户加入社区：`community_members`
- 热门标签：`tags`

### 管理后台首页

- 用户数：`users`
- 内容数：`contents`
- 待审核：`contents.status = pending`
- 活跃作者：最近 30 天 `contents.author_id` 去重

## 仍存在的数据一致性风险

### 1. `views` 与 `view_count` 双字段并存

数据库 `contents` 中仍存在：

- `views`
- `view_count`

页面主展示口径基本使用 `view_count`，但以下逻辑仍有地方读取 `views`：

- 推荐算法
- Agent API
- 某些内容推荐相关逻辑

#### 风险

- 首页展示浏览量与推荐排序口径可能不一致
- API 返回浏览量与页面实际显示可能不一致

### 2. 某些产品文案是静态站点文案，不是数据库内容

例如：

- “连接 AI 开发者与创作者的技术社区”
- “连接开发者、创作者与实验现场”

这些属于产品 copy，不属于假数据，但也不是数据库字段。

## 当前结论

就生产页面的“用户可见数据”而言，这轮已经把最明显的硬编码假数据清掉了，尤其是：

- 首页
- 搜索页
- 管理后台首页

现在最大的剩余问题不是“页面还在写死假列表”，而是“同一业务指标在不同地方使用了不同数据库字段”，其中最典型的是：

- `views`
- `view_count`

## 下一步建议

### 第一优先级

统一内容浏览量字段口径，只保留一个标准字段，建议统一到 `view_count`。

### 第二优先级

继续扫描以下页面是否有“真实字段已存在，但页面仍未接入”的问题：

- `explore`
- `trending`
- 社区列表页
- 用户主页统计区

### 第三优先级

如果后续要进一步杜绝回归，建议增加一个“生产页面硬编码数据扫描”规则，至少对以下模式做检查：

- 大数组对象常量
- `defaultStats`
- `defaultTrending*`
- `mock` / `fake` / `sample` 数据块
